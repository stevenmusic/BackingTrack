# City Pop 逼近真歌的計畫(2026-09-26 起)

Steven 的目標:**以上傳的真實歌曲為基準**。音色真實;伴奏型態靈活,不要整個進行都是一樣的節奏;
所有樂器的輕重音律動要對;吉他的音符排列要是真的手型。

這份計畫的用途:**每一步都用同一把尺、同一個接受條件**,分數只准往目標走,走錯就退回,不會來回繞。

## 1. 固定的尺(不准一邊改一邊換尺)

| 尺 | 量什麼 | 工具 |
| --- | --- | --- |
| **律動輪廓** | 每條分軌在「正拍 / e / & / a」四種位置的平均起音強度(每小節除以自己的最大值) | `vary.py`(`<軌>.位置.*`) |
| 輕重音 | 小節內的輕重對比、正拍比 | `vary.py` |
| 型態變化 | 相鄰小節相似度、同型比例 | `vary.py` |
| 風格 | 延伸音、other 亮度等 | `style.py`、`bright_active.py` |
| 規則 | 旋律上的和弦外音 = 0、下數 ≠ 0 | `harmony.mjs`、`allharm.sh` |
| 響度 | peak ≤ 0.85、零削波、RMS −11～−14 | `render.mjs` 的輸出 |

- 參考組固定:**真歌 26 首(上傳 13 + 合集 13)+ Suno 16 首**,兩邊都算正確答案
- 每個特徵都先量人聲滲漏(`oursmel` 配對),**滲漏超過差距的 30% 的特徵不當依據**
  (目前排除:吉他相鄰相似 47%)
- 「目標範圍」= 參考組的四分位(25–75%);只看平均會被極端值拉走

## 2. 總分(看得出有沒有在接近)

**距離 D** = 每條軌、每個被採用的特徵,「我們的平均」到「參考組四分位範圍」的距離
(在範圍內 = 0),除以參考組的四分位寬度,全部加起來。

- 每一輪記在 `tools/realism/db/progress.json`:版本、D、各項分數、n
- **D 只准變小**。變大就退回上一版,不管單一項目多好看

## 3. 每一輪的做法(一次只動一層)

1. **找最大的差距**:從總分裡挑貢獻最大、穩定(區間不跨 0、真歌 vs Suno 分得開的上限 < 0.6)的那一項
2. **讀程式找原因**:那一層的格子、力度、音長是怎麼來的(先搜 `docs/HISTORY.md`,很多「為什麼不這樣做」在那裡)
3. **做 2–3 個候選**,全部寫成 `FEELS[x]` 的欄位、用 `ovr` 蓋,**預設不動**
4. **A/B**:4 組 City Pop 進行 × comp × 30 秒(`cases_acc.json` 那種寫法)→ 拆軌 → 量
5. **接受條件**(四個都要過):
   - 目標那一項往參考組走,而且 4 組進行的配對差**方向全部一致**
   - 總分 D 變小
   - 其他已採用的特徵**沒有一項變差超過它自己的四分位寬度的 25%**(不准拆東牆補西牆)
   - 規則全過:旋律 0 違規、下數 ≠ 0、peak ≤ 0.85、零削波
6. **過了**:在 `progress.json` 記一筆,候選留在分支上(預設仍不開)
7. **沒過**:記下原因(寫進 `docs/REVIEW.md`),換下一個候選或下一層

## 4. 層的順序(先骨架、後裝飾)

律動是鼓與貝斯定的,吉他鍵盤是跟著它們走,所以照這個順序,前一層站穩才動下一層:

1. **鼓**:輕重音輪廓(& 與 a 太重)
2. **貝斯**:正拍太輕、a 的推拍太多
3. **切音吉他**:正拍重音、右手一直在走的十六分
4. **鋼琴 / 鋪底 / 銅管**:輕重對比
5. **型態變化**:小節與小節、樂句與樂句之間的變化(過門、第四層進出),這時候才看,
   因為輕重音不對時量出來的「變化」沒意義
6. **音色**:最後才看(Steven:音色庫 OK,問題在風格特徵)

## 5. 跟 Steven 對答案(盲聽是最後的標準)

- 每接受 **2–3 輪**,做一次盲聽檔(改前 / 改後,RMS 對齊,A / B 由固定種子決定、對照表不給看)
- **盲聽通過才改預設**,另開 PR;沒過就退回,並把 Steven 的描述寫進 `docs/REVIEW.md`
- 量尺與耳朵衝突時**以耳朵為準**,同時檢查量尺哪裡錯了(那一項從總分拿掉或改量法)

## 5.5 改法從哪裡來(Steven:「透過外部搜尋學每種樂器該怎麼編,編好再跟真歌比」)

**分軌量不出每一格怎麼打**(`pattern.py` 驗證沒過),所以改法的來源換成**編曲教學與樂手的做法**,
量尺只用來擋明顯壞掉的東西,好不好由盲聽決定。2026-09-26 查到、跟程式逐條對照的結果:

| 教學的做法 | 我們 | 處理 |
| --- | --- | --- |
| 鼓:大鼓與小鼓固定成簡單的型,律動的波浪交給 hi-hat | 大鼓每小節隨機換型 | `kickHold`(整段固定、句尾才換) |
| hi-hat 十六分,重音 100、弱拍 65–75 | e .42 / & .72 / a .45(振幅,力度約平方換算 → 對得上) | 不動 |
| 小鼓幽靈音 40–60(正拍 100–110);反拍大鼓 60–80 | 0.13 / 0.6、`kickAcc` .68–.78(換算對得上) | 不動 |
| 吉他:右手一直走十六分上下,不響的地方刷悶音 | 悶音只在 e / a、20% 機率 | `parts.chopBrush` |
| 吉他:1–3 弦(或 1–4 弦),低音弦悶掉 | 從 A3 排,約 2–4 弦 | `parts.chopFrom: 60` |
| 鍵盤:一台撐長音、一台打十六分 | 鋪底 + 鋼琴 | 一樣 |
| 貝斯:切分、提早進拍、幽靈音 | 都有 | 一樣 |

來源(搜尋摘要;原網頁被網路限制擋住,細節以摘要為準):
sleepfreaks-dtm.com「生っぽいドラムの打ち込み(ベロシティ編)」、kensukeinage.com「基本ビートの打込み①」、
note.com/10key10key「DTMドラム打ち込み例 その1〜シティ・ポップ風」、guitarmagazine.jp「シティ・ポップ名盤の頻出ギター・コード・フォーム帳」、
core-ms.net「シティポップ楽曲制作の完全ガイド」、tabstock.net「ブラッシング」

錄音設定 `tools/realism/cases_src.json`(每一條單獨對 base)。

## 6. 停下來找 Steven 討論(Steven:「方向錯誤請隨時停止,跟我討論。之前已經從頭不只一次了」)

遇到下面任何一種,**先停手、不再開新的一輪**,帶著數據與選項找 Steven:
- 同一層**連續兩輪被退回**(候選都沒過接受條件)
- 總分 D **兩輪都沒有變小**
- 量尺跟盲聽結果**衝突**(Steven 說變差,但分數說變好,或反過來)
- 要動的東西碰到 `CLAUDE.md`「先問」的規則(換音色、真人片段庫、刻意不做的項目),或要推翻 `docs/HISTORY.md` 裡盲聽決定過的事
- 要改的方向需要**整個重寫**某一層(不是調欄位)——那就是「從頭再來」,先問

討論時要帶:哪一層、試過什麼、D 的變化、為什麼判斷方向錯、兩到三個選項與取捨。

## 7. 每一輪都照做的事

- 走分支 + PR,送審查員(`reviewer`,high effort),審查原文貼 PR、逐條回應
- 量完刪大檔(分軌、wav)
- 回報寫:這一輪動哪一層、D 從多少到多少、有沒有被退回
