# 審查規則

審查員(`.claude/agents/reviewer.md`)每一次都要**逐條**對照下面全部九條,不能只看主對話指定的部分。
每一則意見都要標級別:**阻擋** / **建議** / **需 Steven 聽過**。

## 1. 規則與未結案議題
對照 `CLAUDE.md` 的全部規則,以及 `docs/REVIEW.md` 裡**還沒結案**的議題,檢查這次改動有沒有違反。
違反 `CLAUDE.md` 的絕對規則(單檔、`Math.random()`、setTimeout 排音符、旋律只准和弦音、授權…)一律**阻擋**。

## 2. 數字要能重現
報告、commit 訊息、文件裡宣稱的數字,必須有測試或腳本可以重現(寫出指令與輸入)。
找不到重現方法的數字標為「**未驗證**」;用未驗證的數字當改程式的理由,**阻擋**。

## 3. 量尺與統計要附樣本數與不確定度
任何量尺或統計結論,都要附**樣本數**與**不確定度**(例如 bootstrap 95% 信賴區間)。
樣本太少、或信賴區間跨過「沒差別」(z 跨 0、差值跨 0、AUC 跨 0.5)的結論,只能標「**趨勢**」,
**不能拿來改程式**;拿趨勢改程式,**阻擋**。

## 4. 分軌比較要檢查拆軌偏差
用分軌(Demucs 等)比較時,要檢查**人聲滲漏**等拆軌偏差:參考曲有人聲、我們沒有,
主旋律會漏進 piano / other / guitar。這類特徵不能直接比;要先量化偏差(例如在我們的伴奏混入旋律再拆一次),
偏差量級跟差距同級或更大時,該特徵不得當改程式的依據(**阻擋**)。

## 5. 真人片段的時間與力度
真人片段(Groove MIDI 等)的時間偏差以**毫秒**計,**不可隨速度等比放大**(存成「拍的比例」再乘以拍長就是等比放大),
要有上限。搖擺的片段要用三連音格子量微時值,不能拿十六分格子量。
換串(從一串片段換到另一串)時,要量換串那一小節前後的力度差,沒有正規化就**阻擋**。

## 6. 授權
新增任何音源或資料集,都必須在 `docs/LICENSES.md` 登記授權原文與出處。
**非商業授權或授權不明,一律阻擋。**

## 7. 中英文版面
改到畫面的,中文與英文介面都要驗(`CLAUDE.md`「介面」那節的尺寸);**任何溢出都阻擋**。
沒有附中英文量測結果的版面改動,**阻擋**。

## 8. 聽感交給 Steven
聽感相關、無法用數據判斷的地方,標「**需 Steven 聽過**」,不要猜。
**量尺只指方向,最後由 Steven 的耳朵決定。**根據量尺改聲音的提案,每一項都要附「改前 / 改後」音檔名稱。

## 9. 意見的級別
- **阻擋**:違反規則、數字無法重現卻拿來當依據、授權問題、版面溢出、會壞掉的程式
- **建議**:可以更好但不影響合併
- **需 Steven 聽過**:只有耳朵能決定的事
