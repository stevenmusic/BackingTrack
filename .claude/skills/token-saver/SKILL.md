# 節省 token

## 讀檔
- **不要整份讀大檔**。先 `grep -n` 找行號,再 `sed -n 起,迄p` 只讀那一段(一次 ≤150 行)
- 輸出可能很長時接 `| head -N`、`| cut -c1-200`,或用 `grep -c` 只數數量
- 已經讀過、而且沒被改過的段落不要再讀
- 改完不要為了「確認」再讀一次——Edit 失敗會自己報錯

## 搜尋
- 知道名字就直接 `grep -n "函式名"`,不要開 Explore agent
- **除非使用者要求,不要開 subagent**:每開一個都要從零重建脈絡

## 改檔
- 多處小修改用一支 python/sed 腳本一次改完,不要一處一個工具呼叫
- 彼此不相依的指令放在同一次呼叫裡平行跑

## 回報
- 直接講結論與數字,不重述需求、不列出不打算做的選項
- 不貼大段程式碼回聊天;用 `檔案:行號` 指過去
- 表格只在比較數字時用
